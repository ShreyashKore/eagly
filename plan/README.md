# Plans and future work

This folder holds plans, explorations and future work for things Eagly does not do yet.
[`docs/`](../docs/) describes only what is built. When a plan lands, its built part moves to
`docs/` and the plan file is trimmed or deleted. A plan file that shares a name with a file in
`docs/` continues it, and keeps its section numbers.

- [COMPANION_APP.md](COMPANION_APP.md): what an Eagly app on the phone could do and how much
  desktop code it could reuse. An exploration; nothing is decided.
- [IOS_SCREEN_MIRROR.md](IOS_SCREEN_MIRROR.md): what the iPhone mirror doesn't do yet.
- [LAYOUT_INSPECTOR.md](LAYOUT_INSPECTOR.md): Flutter and iOS layout inspection, an Inspektor
  `layout` module, and the open points left when work paused after phase 2.
- [MCP_SERVER.md](MCP_SERVER.md): phase 2 of the MCP server (actions), what is left of phase 1,
  and the open questions.
- [NETWORK_INSPECTOR.md](NETWORK_INSPECTOR.md): phases 3 to 5 of the network inspector, risks,
  spikes, open questions and research notes on routes not built yet.
- [NETWORK_INSPECTOR_DROPPED_ROUTES.md](NETWORK_INSPECTOR_DROPPED_ROUTES.md): capture routes and
  transports that were evaluated and dropped, kept so revisiting one starts from the facts.
- [PLUGIN_SYSTEM.md](PLUGIN_SYSTEM.md): a plan for third-party plugins.
- [PLUGIN_AUTHORING.md](PLUGIN_AUTHORING.md): the plugin author's guide that goes with that plan.
- [WORKSPACE_LAYOUT.md](WORKSPACE_LAYOUT.md): what the device workspace doesn't do yet.
